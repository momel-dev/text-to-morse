# Text to Morse Converter

## Description

A simple Python application that converts text into Morse code.

## Features

- Converts letters and numbers into Morse code
- Supports common punctuation marks
- Preserves unsupported characters
- Handles spaces between words

## How to Run

1. Clone the repository.
2. Run the program with Python.
3. Enter the text you want to convert.
4. The Morse code will be displayed in the terminal.

## Example

Input:
Hello World!

Output:
.... . .-.. .-.. ---   .-- --- .-. .-.. -.. !
